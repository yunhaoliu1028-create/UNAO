# Unao Solution

Web-based SaaS for auto body shops to generate consumables invoices from estimate PDFs (CCC, Mitchell, Audatex).

## Repository Structure

- `docs/`: architecture and product specifications
- `backend/`: API contracts and data model starter files
- `frontend/`: UI information architecture and screen specs

## Implemented From Roadmap

This repository contains implementation artifacts for:

1. Technical stack decisions and non-functional requirements
2. MVP scope with user stories and acceptance criteria
3. Initial ER model and database schema
4. End-to-end estimate-to-invoice flow and API contracts
